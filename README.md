All the scripts asuumes the installation of pylake module.
Install lumicks pylake from here (https://lumicks-pylake.readthedocs.io/en/stable/install.html)
Try to install anaconda first then use these scripts. 
If you want to pursue interactive visualisation of the files, you need to use spyder for which you could just open through anaconda, bash or app list. Need to install pylake there as well. 
Raw data for a reference will be given for each scripts for your visualisation and to play around.
